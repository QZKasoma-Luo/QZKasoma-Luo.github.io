A validation framework for IoT and Internet of Underwater Things datasets. It scores data
quality and checks network-flow assumptions before modelling, including missing values,
duplicate rows, flow-rate consistency, TCP flags, DDoS patterns, and underwater latency and
bandwidth expectations.

The repository pairs the validation scripts with a scoring program and a notebook for DDoS
detection experiments under network noise.
