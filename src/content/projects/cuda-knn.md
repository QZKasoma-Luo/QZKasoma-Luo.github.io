A group project exploring GPU acceleration for k-nearest neighbours on the MNIST dataset.
The implementation uses multi-stream processing, a bitonic-sort kernel, and explicit memory
management; the repository reports a 96.65% baseline accuracy before further GPU tuning.

The site labels this as a **group project** and does not attribute the team’s result to one
person.
